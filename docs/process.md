# StockVal 开发进度跟踪（process.md）

> 本文档是开发过程的唯一进度台账，需求依据见 [PRD.md](PRD.md)。
> **每完成一项任务，必须同步更新：任务状态、阶段汇总计数、变更日志。** 开始任务时也要先标记为进行中。

## 1. 状态说明

| 标记 | 含义 | 使用规则 |
|---|---|---|
| ⬜ | 未开始 | 默认状态 |
| 🚧 | 进行中 | 开始动手时改为 🚧，填写开始日期 |
| ✅ | 已完成 | 通过验收标准后改为 ✅，填写完成日期与一句备注 |
| ⛔ | 阻塞 | 填写阻塞原因与解除条件 |
| ⏸ | 暂停 | 填写暂停原因与恢复条件 |
| ➖ | 不做/取消 | 说明原因，不删除任务行 |

**更新协议**

1. 任务开始：⬜ → 🚧，填写开始日期。
2. 任务完成：🚧 → ✅，填写完成日期、关键产出/PR 链接/测试结果。
3. 任务阻塞：🚧 → ⛔，写明原因；解除后回到 🚧。
4. 每次状态变化同时更新第 2 节汇总计数与第 10 节变更日志。
5. 不删除任务行；范围变化用 ➖ 标记并说明。
6. 代码提交与进度更新放在同一次提交中，避免台账与代码不一致。
